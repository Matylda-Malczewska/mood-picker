# Mood Picker

An AI-powered web app that recommends music playlists and movies based on your current mood.

## How it works

1. Describe how you're feeling in the text box
2. AI analyzes your mood using Groq (Llama 3.3)
3. App recommends a matching Spotify playlist and YouTube video

## Tech Stack

- **Backend:** Python, Flask
- **AI:** Groq API (Llama 3.3-70b)
- **Music:** Spotify Web API
- **Video:** YouTube Data API v3
- **Frontend:** HTML, CSS, JavaScript

## Features

- Natural language mood analysis
- Personalized Spotify playlist recommendations
- Matching YouTube video suggestions
- Aesthetic scrapbook-style UI
